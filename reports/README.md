# СКУД Gate — веб-сервис мониторинга и отчётов

Полноценный веб-сервис по журналу СКУД **Gate-IP**: вход по логину/паролю,
живой поток проходов, графики, отчёты посещаемости и выгрузка для 1С.

**Адрес:** http://192.168.2.72:8095/
**Вход:** `vitosamin` / `Admin910327` (меняется в `gate.config.json` → `auth`)
**Оформление:** светлая деловая тема в стиле 1С:Предприятие (плотные таблицы,
синие акценты, без градиентов и «неона»)

```
Мониторинг      KPI дня, лента проходов вживую (Server-Sent Events),
                «на объекте сейчас», график проходов по часам, любой прошедший день
Аналитика       динамика по дням, вход/выход по часам, опоздания (пончик),
                распределение времени на объекте, тепловая карта «день недели × час»,
                подразделения, топ опоздавших
Журнал событий  свёрнутый блок: все события СКУД (устройства, тревоги, связь,
                операторы); фильтры: событие из списка, ФИО/табельный, тип,
                только тревоги; грузится только при раскрытии
Посещаемость    приход/уход/часы по сотрудникам, опоздание и ранний уход от границ
                смены; виды: по дням · свод · опоздания · не приходили;
                итоговые строки, печать, Excel, CSV
Карточка        клик по любому ФИО (в отчёте, ленте, «на объекте») — история
сотрудника       проходов за период, часы по дням, опоздания
Отчёты          отдельная вкладка: все отчёты Gate в одном месте с счётчиками —
                УРВ, свод, опоздания, не приходили, пользователи, события, 1С;
                у каждого: CSV, Excel и информативная печать
Выгрузка в 1С   CSV (Windows-1251, «;», запятая в дробях), Excel (.xls), печать/PDF
```

## Авторизация

- Форма входа `/login`, пароль проверяется на сервере.
- Сессия — подписанная HMAC-cookie на 12 часов (`session_hours`).
- Без сессии: HTML → редирект на `/login`, API/выгрузки → `401`.
- Дополнительно принимается HTTP Basic (удобно для скриптов и curl).
- Выход — кнопка «⎋ Выход» (`/logout`).

## Откуда данные

Сервер Gate-IP `192.168.2.160`, SMB-шара `\\192.168.2.160\GATE`:

| Что | Путь | Содержимое |
|---|---|---|
| Суточный журнал | `Server\Events\nГГММДД.mdb` | таблица `Events` — все события дня |
| Конфигурация | `Server\config.mdb` | `Users` (сотрудники), `Groups` (подразделения), `Devices` (двери) |

Проход = `EventType=1` и `EventCode=8` («Проход совершен»); направление
(вход/выход) определяется по названию точки, напр. `КПП1 - Вход`.

**Приход** — первый проход дня, **уход** — последний. Для сегодняшнего дня у тех,
кто ещё внутри, часы считаются до текущего момента и ставится метка «на объекте».
Опоздание и ранний уход считаются от границ смены (по умолчанию 08:00–17:00,
меняются в интерфейсе).

Сервис сам раз в 45 секунд догружает сегодняшний журнал и раз в 10 минут
обновляет список сотрудников.

## Запуск

```bash
cd /home/dsh/projects/gates/reports
./run.sh                 # или: python3 server.py 8095
```

Порт задаётся в `gate.config.json` (`port`) или первым аргументом.

### Автозапуск при загрузке машины

Сервис установлен как systemd-юнит `gate-reports` (`enabled`, `Restart=always`),
работает от пользователя `dsh`:

```bash
systemctl status gate-reports          # состояние
sudo systemctl restart gate-reports    # перезапуск
sudo systemctl stop gate-reports       # остановить
tail -f /home/dsh/projects/gates/reports/gate-reports.log
```

Юнит лежит в `systemd/gate-reports.service`, ставится/переустанавливается:

```bash
sudo sh /home/dsh/projects/gates/reports/systemd/install.sh
```

> Запуск из песочницы DSH невозможен: `sudo` для пользователя `dsh` запрещён
> политикой. Устанавливать юнит нужно в обычном терминале на машине.

`ensure.sh` — резервный сторож на случай, если systemd недоступен: поднимает
сервис, только если порт не занят (защита от двойного запуска через `flock`).
Можно повесить в crontab: `*/5 * * * * /home/dsh/projects/gates/reports/ensure.sh 8095`.
**Не включайте одновременно systemd и cron** — они будут драться за порт.

## API

Все эндпоинты (кроме `/login`) требуют сессию или Basic-авторизацию.

| Запрос | Что отдаёт |
|---|---|
| `GET /api/status` | состояние базы, время последней синхронизации |
| `GET /api/kpi?day=` | проходы, входы/выходы, на объекте, тревоги, по часам |
| `GET /api/stream?day=` | **SSE**: поток проходов вживую |
| `GET /api/live?day=&limit=&all=1` | лента событий (`all=1` — вместе с дверными) |
| `GET /api/presence?day=` | кто на объекте (последний проход — вход) |
| `GET /api/analytics?from=&to=&group=&point=` | данные для всех графиков + сравнение с прошлым периодом |
| `GET /api/late?from=&to=&group=&search=` | опоздания по сотрудникам |
| `GET /api/person?user_ptr=&from=&to=` | карточка сотрудника: дни, часы, опоздания |
| `GET /api/users?group=&search=&user_ptr=` | отчёт о пользователях |
| `GET /api/employees?group=` | справочник сотрудников по алфавиту |
| `GET /api/reports/preview?from=&to=` | счётчики для вкладки «Отчёты» |
| `GET /api/events/summary?from=&to=` | сводка журнала событий СКУД |
| `GET /api/events/list?from=&to=&type=&search=&message=&alarms=1&limit=&offset=` | журнал событий (`search` — ФИО/табельный/текст, `message` — точное событие) |
| `GET /api/points`, `/api/groups` | контрольные точки, подразделения |
| `GET /api/report?from=&to=&view=&group=&point=&search=&shift_start=&shift_end=` | отчёт |
| `GET /api/sync?days=3` | догрузить журнал |
| `GET /export/1c.csv?...&enc=cp1251&sep=semicolon&dec=,&header=1` | файл для 1С |
| `GET /export/report.xls?...` | оформленный отчёт для Excel |
| `GET /export/users.csv`, `/export/users.xls` | отчёт о пользователях |
| `GET /export/events.csv?from=&to=&message=&alarms=1` | весь журнал событий в CSV |
| `GET /print?view=detail\|summary\|late\|absent\|users\|events&...` | печатный документ (→ PDF из браузера) |

`view`: `detail` (по дням) · `summary` (свод) · `late` (опоздания) · `absent` (не приходили).

Пример через curl:

```bash
curl -s -u vitosamin:Admin910327 http://192.168.2.72:8095/api/status
curl -s -u vitosamin:Admin910327 -o otchet.csv \
  "http://192.168.2.72:8095/export/1c.csv?from=2026-11-01&to=2026-11-17&enc=cp1251"
```

## Выгрузка в 1С

Колонки CSV:

```
ТабельныйНомер;ФИО;Подразделение;Должность;Дата;Приход;Уход;Часов;
Проходов;ОпозданиеМин;РаннийУходМин;КонтрольныеТочки
```

Для 1С:Предприятие 8 под Windows — кодировка **Windows-1251**, разделитель
**точка с запятой**, дробная часть — **запятая**, строка заголовков — **да**.
Читается через «Загрузка данных из файла» / «Список значений → Загрузить из файла».

Файлы скачиваются через `fetch` + Blob, поэтому загрузка не блокируется
браузером и внизу справа появляется подтверждение с именем и размером файла.

## Ограничения

- Учётные данные Gate и пароль сервиса лежат в `gate.config.json` открытым
  текстом — файл не публиковать, доступ к сервису только в локальной сети.
- Данные обновляются не мгновенно, а раз в 45 секунд (Gate пишет журнал файлами).
- Опоздание/ранний уход зависят от границ смены: для сменных цехов задавайте
  свои значения в фильтрах отчёта.
- Графики нарисованы собственным SVG-кодом (без Chart.js и CDN) — работает
  в закрытой сети без интернета.

## Что можно добавить дальше

- **Живые уведомления о тревогах** — всплывающее окно и счётчик в шапке при
  «Взлом двери» / «Дверь не закрыта» (SSE уже есть, нужно расширить поток).
- **Отчёт по расписанию на почту** — утренняя сводка за прошлый день.
- **Формат для 1С напрямую** — JSON-эндпоинт вместо CSV, чтобы 1С забирала
  данные HTTP-запросом, без ручной выгрузки.
- **Табель Т-13** — выгрузка в формате, который 1С:ЗУП принимает без правки.
- **Роли** — охранник (только мониторинг), кадры (отчёты), руководитель (всё).
- **Мобильная вёрстка** — сейчас адаптив базовый; можно довести до телефона.
- **«Нет на месте N дней»** — автосписок тех, кто пропал с радаров.
- **Тёмная тема** — для ночной смены.

## Печать отчётов

`Печать` открывает готовый документ и сразу вызывает диалог печати:

- шапка: название отчёта, пояснение, период, число записей, дата формирования;
- блок показателей (сотрудников, человеко-дней, часов, минут опозданий…);
- таблица с **повтором шапки на каждой странице** и запретом разрыва строки;
- колонтитул с источником;
- A4: альбомная для «УРВ» и журнала событий, портретная для остальных;
- из диалога печати сохраняется в PDF.

Журнал событий печатается не больше 2000 строк за раз (в шапке видно «Показано»);
полный журнал — через CSV.

## Выбор сотрудника по фамилии

Во вкладках **«Отчёты»**, **«Посещаемость»** и **«Выгрузка в 1С»** есть поле
**«Сотрудник»** — выпадающий список всех работников по алфавиту (287 человек).
Работает как обычный select: начните печатать фамилию — список перескочит
на неё.

Выбранный человек фильтрует **все** отчёты и выгрузки: УРВ, свод, опоздания,
не приходили, отчёт о пользователях, журнал событий, CSV для 1С и печать.
Пустое значение — все сотрудники.
