## Проект
Android-приложение **«Доступ»** (пакет `ru.smartsystem39.gates`, репозиторий vorota): пульт Gate-IP, Home Assistant и HTTP (Java, без Gradle), веб-версия и Windows-мост. Описание — `README.md`, выпуск — `RELEASING.md`. Имя файла релиза осталось `Vorota.apk`, чтобы не ломать постоянную ссылку.

## Оформление 3.7 — тёмно-зелёный акцент, дымчатые темы
Макет: `design/mockup.html` (HTML с настоящими SVG панели, открывается в браузере).
Инструменты: `design/lucide.py` (извлекает иконки Lucide из бандла панели и генерирует
vector drawable), `design/build_mockup_html.py`, `design/check_panel_colors.py` (26 пар цветов, включая значки).

- Иконки — Lucide из `singbox-manager/internal/web/static/lucide.min.js`: дверь, шлагбаум, вход/выход, стоп, сетка, шестерёнка, звезда, корзина. Штрих 2, концы скруглённые.
- Палитра панели: тёмная (по умолчанию) фон `#10141a`, карточки `#1a222c`, рамка `#27323f`, текст `#e7ecf3`, акцент `#4a9eff`, заливка `#2b62d9`; светлая `#f1f2f4`, `#fbfbfc`, `#2b62d9`, `#1d4ed8`.
- Устройства — компактные плитки по две в ряд. Высота 158, а у двери с двумя направлениями 204: кнопки стоят столбиком. В плитке: значок 28, название 15→12sp в две строки, подпись 11, статус 11, кнопки 34.
- Значок типа — белый глиф на цветной плашке с лёгким объёмом (`Ui.chip`: градиент светлее→темнее). Двери (калитка и ворота) — тёмно-зелёные `#1b5e3a` / `#2f8a5b`, шлагбаум оранжевый, реле сиреневое. См. `Device.typeColor`.
- Акцент — тёмно-зелёный: светлая `#1b5e3a`, тёмная `#57b98c`. Синего и голубого нет вообще.
- Поверхности — сероватая дымка: тёмная `#121316`/`#1b1d21`, светлая подложка `#dee1e4`, карточки `#f4f5f6`. Чистый белый убран, подложка темнее карточек.
- **Имя двери задаёт человек** (`Device.nameEdited`): импорт из моста не перезаписывает. Долгое нажатие на плитку — меню «Переименовать / Настройки / Избранное».
- Дверь Gate-IP хранится как `P_CUSTOM`, но своего URL не имеет: редактор **не должен требовать URL открытия** и не показывает эти поля (иначе переименование падало). Пустой адрес подставляется из `cfg.getGateUrl()`.
- Заготовки «Ворота/Калитка/Шлагбаум» узнаются по метке `Device.seed`, а не по имени, иначе после переименования создавались бы заново. Старые записи мигрируют по имени.
- Состояние показывают **пульсирующие огоньки**: в шапке и на каждой плитке. Такт `PULSE_PERIOD` 4200 мс, волна 1,3 с, яркость 0.55–0.85 — редко и не ярко. Плитки пульсируют одним `ValueAnimator` по флагу `Card.live`.
- Текст состояния убран с плиток (остался в contentDescription); в шапке подпись выводится только для подсказок — `setHeader(..., true)`.
- Иконка приложения — дверь Lucide на тёмно-зелёном градиенте (`design/make_icons.py`, `ic_launcher_background.xml`). Знак занимает 56 % плашки, как foreground adaptive-icon.
- Иконка в кнопке задаётся вручную: 13 dp через `setBounds` в `Ui.styleButton`, отступы 6 dp, подпись 11 sp — иначе вектор не влезает в узкую кнопку плитки.
- «Вход» и «Выход» — одинаковые кнопки 34 dp во всю ширину, «Вход» сверху: `btn_in` (зеленоватая подложка `accent_soft`) и `btn_out` (красноватая `danger_soft`). Подписи — `accent` и `danger`.
- Распорка с весом 1 перед кнопками прижимает их к низу плитки: в ряду кнопки соседних плиток на одной линии.
- Главное действие — на `btn_tint` (мягкая акцентная подложка), как tinted-кнопка в iOS.
- Синий только там, где он в панели: активная вкладка, значки, кнопки сохранения. Действия устройств — нейтральные кнопки, главное выделено цветом текста.
- Избранное в плитке не помещается: отмечается в редакторе (долгое нажатие на плитку).
- В панели акцент для текста и заливки под белый текст — разные цвета (`--accent` и `--accent-fill`); в приложении так же (`accent` и `accent_fill`).
- **Грабля:** `design/lucide.py` пишет имена вида `ic_trash_2` (цифры через подчёркивание). Иконки генерируются 18dp — столько нужно для compound drawable в кнопках.

## Соседняя работа
В репозитории параллельно правится `reports/web/` (другая сессия). Коммитить только свои пути, не `git add -A`.

## Безопасность — требует решения
- Общий токен моста встроен в APK и передаётся в URL; доверенный HTTPS-прокси пропускает токеновый GET `/open` без сессии и 2FA. Нужны смена токена и новая авторизация. Сервер не менялся.
- HA по HTTP передаёт токен открыто; токены в SharedPreferences, не зашифрованы.
- Импульс Tasmota/ESPHome выключается телефоном: при сбое OFF может не дойти. Нужен таймер устройства.

## Мост и грабли
Мост `bridge/GateBridge.cs`, 192.168.2.160:8099; собирать `/target:winexe`. Подробности — `reports/README.md`.

Не менять сортировку GateTerm (ломается калибровка), GateServ под HASP не патчить, `build.sh` удаляет `build/`.
