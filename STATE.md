## Безопасность — требует решения
- Общий токен моста встроен в APK и передаётся в URL. По исходникам доверенный HTTPS-прокси пропускает токеновый GET `/open` без сессии и 2FA. Сменить токен, переработать авторизацию сервера и клиента. Пользователь просил опубликовать 2.7 — релиз выпущен с этим предупреждением; токен уже был в релизах 1.0–2.6. Сервер не менялся.
- HA по HTTP передаёт токен открыто; отключение проверки HTTPS небезопасно. Токены в SharedPreferences, не зашифрованы.
- Импульс Tasmota/ESPHome выключается телефоном: при сбое OFF может не дойти. Нужен таймер устройства. Тестировать на моках либо с разрешения пользователя.

## Мост и грабли
Мост: `bridge/GateBridge.cs`, 192.168.2.160:8099. Собирать `/target:winexe`: консоль перехватывает фокус. Подробности `reports/README.md`, прежние STATE в git.

Не менять сортировку GateTerm — ломается калибровка; «Заблокировать» отключает карты. GateServ под HASP не патчить. Очередь даёт 2–4 с; прямую запись в CommandQuetch пользователь запретил. Контроллер допускает одно TCP-подключение. Остальные грабли — в git-истории STATE.

`build.sh` удаляет `build/`: сначала проверка и согласие на удаление. APK собран в отдельном `/tmp/vorota-final.*`. При смене настроек Gate двери обновляются повторным импортом.
