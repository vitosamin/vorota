# Как выпускать обновления

Приложение проверяет последний релиз GitHub:
`https://api.github.com/repos/vitosamin/vorota/releases/latest`
и сравнивает `tag_name` с `versionName` установленного APK. Если тег новее,
предлагает скачать APK из релиза и открывает системный установщик.

## Шаги

1. Поднять версию в `AndroidManifest.xml`:
   - `android:versionCode` — +1 (обязательно для установки поверх);
   - `android:versionName` — например `1.1`.
2. Собрать: `./build.sh` → `dist/Vorota-1.1.apk`.
3. Закоммитить и поставить тег:
   ```bash
   git add -A && git commit -m "1.1"
   git tag v1.1 && git push && git push --tags
   ```
4. Создать релиз `v1.1` и прикрепить `dist/Vorota-1.1.apk`
   (через веб-интерфейс GitHub или API).
5. Проверить в приложении «Настройки → Обновления → Проверить обновления».

## Важно

- **`release.keystore` не публикуется** (в `.gitignore`). Обновление
  установится поверх только с той же подписью — храните ключ и пароль.
- Имя APK в релизе должно заканчиваться на `.apk`; приложение берёт первый
  такой asset из последнего релиза.
- Тег должен быть вида `vX.Y` или `vX.Y.Z`, иначе сравнение версий даст 0.
- Черновики и prerelease в «latest» не попадают.
